# Duplicate Finder

Утилита автоматизации поиска и анализа файлов-дубликатов в среде операционной системы Astra Linux.

## Спецификация
* **Среда функционирования:** Astra Linux (любые версии, включая Special Edition / Common Edition)
* **Язык реализации:** Python 3 (используются исключительно встроенные библиотеки)
* **Требования к сети:** Интернет не требуется

---

## Возможности
* **Двухэтапный алгоритм:** Быстрая группировка по размеру с последующим точечным вычислением криптографических хеш-сумм.
* **Экономия памяти:** Поблочное чтение файлов (chunks по 4096 байт) предотвращает переполнение ОЗУ на файлах больших размеров (более 5 ГБ).
* **Аналитика:** Автоматический расчет потенциально освобождаемого дискового пространства.
* **Мультиформатный экспорт:** Сохранение отчетов в форматах `.txt`, `.json` и табличном `.csv` (совместим с LibreOffice Calc).
* **Безопасность:** Скрипт работает строго в режиме чтения, не вносит изменений в файловую систему и корректно обрабатывает ошибки доступа.
