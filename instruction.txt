ИНСТРУКЦИЯ ПО ЗАПУСКУ И ИСПОЛЬЗОВАНИЮ УТИЛИТЫ DUPLICATE-FINDER

Наименование: Скрипт анализа и поиска файлов-дубликатов.
Среда функционирования: Astra Linux
Язык реализации: Python 3
Требования к сети: Интернет не требуется

1. ПОДГОТОВКА К ЗАПУСКУ
Перед первым использованием необходимо выставить права на исполнение файла скрипта.
Откройте терминал в папке со скриптом и выполните:
    chmod +x duplicate-finder.py

Если скрипт редактировался в среде Windows, перед запуском удалите скрытые символы:
    sed -i 's/\r$//' duplicate-finder.py

2. ПОЛУЧЕНИЕ СПРАВКИ (--help)
Для вывода описания параметров введите команду:
    ./duplicate-finder.py --help

3. ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

Пример 1: Базовый поиск дубликатов в определенной директории
Поиск в папке '/home/user/docs' с алгоритмом по умолчанию (sha256):
    ./duplicate-finder.py --path /home/user/docs

Пример 2: Смена алгоритма хеширования
Использование алгоритма md5 для проверки:
    ./duplicate-finder.py --path /home/user/docs --hash md5

Пример 3: Экспорт отчета в текстовый файл (.txt)
    ./duplicate-finder.py --path /home/user/docs --export duplicates.txt

Пример 4: Экспорт отчета в структурированный JSON формат
    ./duplicate-finder.py --path /home/user/docs --export report.json

Пример 5: Экспорт отчета в табличный CSV формат (удобно для LibreOffice Calc)
    ./duplicate-finder.py --path /home/user/docs --export data.csv
